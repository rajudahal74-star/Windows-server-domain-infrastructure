# Windows Server Domain Infrastructure Project

## 🧠 Overview
This project demonstrates the deployment and configuration of a Windows Server 2025 Standard domain environment to simulate enterprise network operations.

## 🔧 Features Implemented
- Active Directory Domain Services (AD DS)
- DNS and DHCP configuration
- Group Policy for drive mapping and printer deployment
- Secure file sharing with NTFS permissions and access-based enumeration
- Centralized print management with ARM64-compatible drivers
- User login and access control testing
